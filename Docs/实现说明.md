# 实现说明

## 启动与单局

主场景入口为 `EmberGame`。`Awake` 创建本局状态、输入与选卡控制器；`Start` 装配战斗、菜单、相机与加载页，先隐藏场景中的 UIRoot。字体准备后通过 `EmberMenuUi.Bind` 绑定同一个 UIRoot 实例，加载就绪并继续后进入主菜单。

玩家依次选择局长、难度、槽位数和一把起始武器。`StartRunWith` 创建关卡配置、世界节点、特效与玩家，配置构筑，重置生命与选卡状态，最后调用 `EmberCombat.Begin`。只有 Playing 阶段推进战斗；中途阶段变化立即停止本帧后续战斗处理。

## 主要调用链

| 功能 | 调用链与结果 |
|---|---|
| 移动 / 跟随 | `EmberInput` → `EmberKeeperMotion.Step`：合并键盘与摇杆输入、限幅并钳制边界；`Follow` 更新相机 |
| 刷怪 / 追击 | `EmberWaveDirector.Tick` → `EmberEnemyRoster.Spawn` → `EmberSpawnPlacement.TryFind`：普通/遭遇怪从完整视口外沿带生成，成功才记配额；敌人按对应策略追击 |
| 自动攻击 | `EmberCombat.TickWeapons` → 各 `EmberWeapon.Tick` → context 选敌与投递伤害 → `EmberCombatDamage` |
| 死亡 / 拾取 | 最终死亡结算 → 计分、击杀与波次记录 → `EmberHealingDrops` 按概率生成治疗物；吸附拾取后经宿主调用 `EmberKeeperVitals.PickHealingDrop` |
| 受伤 | `EmberKeeperVitals.Hurt`：阶段/无敌帧检查 → 难度倍率 → 护盾 → 生命；组合根将结果转成音效、HUD 与失败流程 |
| 选卡 | 清波 → `RunFlowController.OnWaveCleared` → `RunProgress.Choices` → 展示模型/面板 → `Choose`；新武器补偿一次、不连锁 |
| 范围伤害 | 火雨落点、环火接触、火海圈与共享燃地遍历目标并投递伤害；共享燃地不要求持有燃地武器 |

治疗掉落允许满血拾取，溢出治疗丢弃。Boss 与分裂子体保留特殊生成位置。完整玩法与数值见 [requirements.md](requirements.md)。

## UI 预制体与编辑器工具

场景的 `EmberGame.uiRoot` 引用 UIRoot 上的 `EmberUiRoot`，`introRoot` 引用 IntroRoot 上的 `EmberIntroView`。布局与静态图片保存在 Prefab 中，运行时更新文字、状态、回调和动态排卡。菜单、HUD、开局选择、设置与升级复用已有控件；加载页结束后隐藏实例。

`EmberFonts.ValidateBaked` 校验预烘字体，失败时回落动态图集。UI 与加载页均在字体准备后使用视图。修改布局可直接编辑 Prefab，日常调整无需重新运行连接工具。

- `Emberlight → UI → Repair UIRoot Images`：修复并保存 UIRoot 图片引用。
- `Emberlight → UI → Repair Selected Images`：修复选中对象的图片引用。
- `Emberlight → UI → Connect UIRoot Runtime`：为旧快照补齐静态控件并配置场景引用；操作后按需保存场景。

`Assets/UI/Generated` 及其 `.meta` 随工程提交。静态控件工厂与旧快照补建仅存在于 Editor；缺少运行时引用或控件容量不足会报告配置错误。

## 职责与扩展位置

- 新武器：在 `EmberWeaponCatalog` 增加身份定义，在 `EmberWeaponTuning` 配置参数，实现 `EmberWeapon.Tick`，最后在 `EmberWeaponFactory` 注册并接入构筑、说明和图标。
- 卡池与构筑：候选生成归 `EmberChoicePool`，状态落地归 `RunProgress`；随机数调用顺序影响相同种子的复现。
- 卡面：武器说明读 Catalog，其他文案读 `EmberCopy`；`EmberOfferPresentation` 生成展示数据，面板负责布局与交互。
- 共享燃地：`EmberBurnGround` 管理生命周期与伤害；武器经 context 投递燃地，战斗根统一推进与清理。
- HUD：条形值跟随状态，文字在对应值变化时格式化，时钟按显示秒更新；Stage 是波次文字的唯一写入点。

## 工程交付

使用 `Tools/export-project.ps1` 导出完整 Unity 工程与源码，包含场景、预制体、资源、`.meta`、依赖清单、项目设置和必要说明。首次导入重新生成 Library；修改工程后重新导出最新包。开发检查命令见 [README](../README.md)。
