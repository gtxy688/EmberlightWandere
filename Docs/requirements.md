> 本文件是**产品行为、约束与数值的唯一权威来源**。
> 架构文档只描述"怎么实现"，不复制这里的数值；发现数值不一致时以本文件为准。
> 最后核对：2026-09-23（§7 中文字体与程序集口径已对照工作区代码修正；数值部分最后核对 2026-09-14）
> 本轮核对：2026-10-15（补齐现有武器、敌人、卡池与表现参数；词缀概率说明经 jack 确认按源码修正，游戏代码与运行值未改）。

## 1. 产品定位与范围

一盏灯芯走在长夜里。虚拟摇杆移动、武器自动开火、清波选卡变强，撑过全部波次即为通关。

| 项 | 内容 |
|----|------|
| 平台 | Android（竖屏）+ Editor 内试玩 |
| 单局时长 | 25 波（推荐）或 50 波 |
| 视角 | 2D 俯视，正交相机，固定竖屏构图 |
| 美术 | 简笔画（doodle）风格，暖色灯芯调；占位美术允许程序生成 |
| 付费 / 联网 | 无 |

## 2. 单局主循环

```text
营地（主菜单）
  → 选征程长度（25 / 50 波）
  → 选难度（休闲 / 标准 / 困难）
  → 选武器槽位上限 N（1–5，默认 2）
  → 单选 1 把起始武器（整库翻页，必须点选）
  → 战斗：逐波清怪 → 清波选卡 → 下一波
  → 每 10 波阶段 Boss；最后 1 波最终 Boss
  → 最终 Boss 死亡 = 通关；生命归零 = 失败
  → 结算（显示本局难度、长度、波数、时间、击杀、Score）
```

**开局不可跳过**：必须选 N 并单选 1 把武器；异常回落为「火球 ×1 + N=2」。

## 3. 局内规则

### 3.1 波次

| 项 | 规则 |
|----|------|
| 波数 | 25 或 50 |
| 第 1–5 波配额 | 12 / 18 / 24 / 30 / 36 |
| 第 6 波起配额 | `min(70, 36 + 2×(wave−5))` |
| 配额修正 | 乘难度 `CountMultiplier` 后取整，下限 1 |
| 刷怪间隔（第 1–5 波） | 0.90 / 0.75 / 0.60 / 0.48 / 0.36 秒 |
| 刷怪间隔（第 6 波起） | `max(0.22, 0.36 − (wave−5)×0.006)` 秒 |
| 间隔修正 | 乘难度 `IntervalMultiplier`，下限 0.14 秒 |
| 清波条件 | 本波配额刷完 **且** 场上敌人为 0 |
| 同时存在敌人上限 | 150 |
| 普通/遭遇杂兵出生 | 完整相机视口外的随机外沿带，且位于地图内；无合法区域时暂缓，不消耗配额 |
| 屏外预留边距 / 外沿带宽 / 地图内缩 | 1.2 / 2 / 0.8 世界单位（LevelConfig 配置） |

Boss 与母体死亡点附近的分裂子体保留现有特殊落点；上述屏外规则不改变其出场机制。

### 3.2 精英与 Boss

| 项 | 规则 |
|----|------|
| 精英挑战波 | 每 5 波，且不是 Boss 波 |
| 阶段 Boss 波 | 每 10 波 |
| 最终 Boss 波 | 第 25 或第 50 波 |
| 阶段 Boss 血量 | `(1600 + wave×100) × HealthMultiplier` |
| 最终 Boss 血量 | 6000（25 波）/ 10000（50 波），再乘 `HealthMultiplier` |
| 暗弹齐射 | 第 20 波起加入，带 1 秒预警；随阶段增加弹数与暗焰落点 |
| 半血狂怒 | 保留 |

### 3.3 难度倍率

> **权威值**。来源：`Assets/Scripts/Core/LevelConfig.cs` —— 2026-09-14「全难度怪血 /2」。

| 难度 | 血量 `HealthMultiplier` | 敌方伤害 `DamageMultiplier` | 刷怪配额 `CountMultiplier` | 刷怪间隔 `IntervalMultiplier` | 词缀概率 `AffixMultiplier` |
|------|------:|------:|------:|------:|------:|
| 休闲 Casual | **0.25** | 0.70 | 0.85 | 1.15 | 0.70 |
| 标准 Standard | **0.5** | 1.00 | 1.00 | 1.00 | 1.00 |
| 困难 Hard | **0.675** | 1.30 | 1.20 | 0.88 | 1.25 |

- 敌方伤害倍率在 `HurtPlayer` **统一应用一次**，覆盖接触、射手、爆炸、灼热与 Boss。
- 每种难度**每局初始生命 100**，无任何永久加成。

### 3.4 敌人血量

| 种类 | 公式（未乘 `HealthMultiplier`） |
|------|--------------------------------|
| 普通 trash | `16 + wave×6` |
| 高血 / 盾卫 tough | `40 + wave×10` |
| 暗烛射手 | `trash × 0.8` |
| 烬胎（母） | `tough × 0.6` |
| 烬虫（子） | `trash × 0.25` |
| 铁灯卫 | `tough × 1.2` |
| 引线虫 | `trash × 0.6` |

### 3.5 精英词缀

| 词缀 | 效果 |
|------|------|
| 灼热 | 2 单位内每秒 2 点伤害，多圈**不叠加** |
| 疾风 | 每 3 秒爆发速度 ×1.8，持续 1 秒 |
| 重生 | 死亡后读条 2 秒，以 40% 生命复活**一次** |

- 随机词缀概率：第 3–4 波为 `12% × AffixMultiplier`；第 5 波起为 `min(50%, (18% + min(12%, (wave − 5) × 0.3%)) × AffixMultiplier)`。增长部分最多增加 12 个百分点，所以标准难度后期上限为 30%；最外层仍保留 50% 的防护钳制。来源为 `LevelConfig.AffixChance`。
- 第 2 波及以前**不出词缀**；精英挑战波的强制小队**不**走随机词缀。
- 词缀怪余烬奖励 ×3。

### 3.6 选卡次数

| 波次 | 每次清波选卡次数 |
|------|------------------|
| 第 1–10 波 | 1 次 |
| 第 11 波起 | 每两波（偶数波）1 次 |
| 阶段 Boss 波 | 在上述基础上**额外 +1**（即连续选 2 次） |
| 最终波 | 直接结算，不选卡 |

- 固定选卡总数：**25 波 = 19 次；50 波 = 33 次**，按上述逐波规则累计，已计入阶段 Boss 的额外次数，不含新武器补偿。
- 每次选卡各自允许一次「获得新武器后的补偿选卡」，补选不消耗后续固定次数，且**不连锁**。

## 4. 构筑与卡池（Gods-Select-v3）

### 4.1 槽位与开局

| 项 | 规则 |
|----|------|
| 槽位上限 N | 1–5，默认 **2** |
| 开局武器数 | **恒为 1**（禁止开局一次填满 N 槽） |
| 空位数 | `N − 1` |
| 满槽后 | 池中**不再出现**「新武器」 |
| 口径 | N 少 = 更稳、更容易成型；N 多 = 更花、更容易歪。**N 不是难度惩罚** |
| ScoreMult | **恒为 1.0**，不做随 N 变化的分数倍率 |

### 4.2 武器花名册（占槽）

| Id | 武器 | 说明 |
|----|------|------|
| 13 | 火球 | 自动锁定最近可见敌人 |
| 14 | 环火 | 环绕火种，接触伤害 |
| 15 | 燃地 | 沿路留火，踩踏掉血 |
| 10 | 穿透火矢 | **基本静止时才开火**，一箭穿多 |
| 11 | 回旋烬蝶 | 去程 / 回程两段均可命中 |
| 12 | 天降火雨 | 预警圈后范围伤害 |


### 4.3 出卡规则

- 候选张数 = `3 + 空位数`，从中**选 1**。
- 基础 3 张来自「通用 / 专属 / 质变」，**同屏唯一键为 `(词条Id, WeaponId)`**：
  - ✅ 可同屏：`火球·攻击力` + `环火·攻击力` + `全体伤害增幅`
  - ❌ 禁止：两张 `火球·攻击力`；三张 `全体伤害增幅`
- 额外张：仅当槽未满时出现的**未拥有武器**，数量 = 空位数。
- 选中**新武器**后立刻补发**一次**选卡（不推进波次）。
- 整局**免费刷新 2 次**；**禁止**出现「+刷新次数」类词条。

### 4.4 通用词条数值（按幸运 roll 品质）

| 词条 | Id | 青铜 | 白银 | 黄金 | 钻石 |
|------|----|-----:|-----:|-----:|-----:|
| 攻击力（**单武器**） | 0 | +10% | +20% | +30% | +40% |
| 攻速（**单武器**） | 1 | +10% | +20% | +30% | +50% |
| 幸运（全局） | 2 | +25 | +50 | +75 | +125 |
| 全体伤害增幅（**全局**） | 3 | +5% | +10% | +15% | +25% |
| 护盾（全局） | 4 | 250 | 500 | 750 | 1250 |

- **攻击力 / 攻速只作用于对应已有武器**，不是全局；不另开全局攻击力（防早期伤害膨胀）。
- **全体伤害增幅**为全局乘区：`构筑伤害 = 武器基伤 × (1 + 单武器攻击力) × (1 + DamageAmp)`；临时 Buff 在实际命中入口再应用，见 §4.10。
- 幸运上限 **120**，影响通用词条品质与专属候选权重；质变门控单独按 §4.6 处理。
- 护盾：选择后立即加算可叠加，受伤时**先乘难度倍率、再扣护盾**，溢出部分扣生命；护盾不自动恢复、新局清零、无局外存档。
- 回血道具：每个回复 20 HP（不超上限），普通敌人最终死亡 8%、带词缀敌人 20%、Boss 100% 掉落；分裂子体不掉落；重生读条前不算最终死亡。

### 4.5 幸运 → 品质权重

> **权威值**。来源：`Assets/Scripts/Core/EmberRarity.cs::WeightsForLuck`（2026-09-13 高品质出率下调）。

| 幸运 | 青铜 | 白银 | 黄金 | 钻石 |
|-----:|-----:|-----:|-----:|-----:|
| 0 | **72** | **22** | **5** | **1** |
| 60 | **58** | **28** | **11** | **3** |
| 120 | **45** | **32** | **18** | **5** |

中间线性插值；通用词条品质通过 `RollByLuck` 读取当前幸运，不按波次门控。

### 4.6 专属（固定黄金）与质变（固定钻石）

| 武器 | 专属（金，Id 30–35） | 质变（钻，Id 20–25） |
|------|----------------------|----------------------|
| 火球 | 连发：额外火球 +1 | 燎原：体积 ×1.5、伤害 ×1.25、命中留燃地 |
| 环火 | 添薪：环绕 +1 | 日冕：半径 / 转速 / DPS 上调 + 灼烧拖尾（单球 DPS 75） |
| 燃地 | 延烧：拖尾更长更烫 | 火海：身周持续火圈 |
| 穿透火矢 | 贯穿：穿透上限 +1 | 穿杨：命中分裂一小支（伤害 ×0.45） |
| 回旋烬蝶 | 回马：往返各多一段结算 | 折返无尽：多一个来回 |
| 天降火雨 | 多落点：+1 落点 | 天火：圈更大、伤更高，参数见 §4.9 |

- 专属 / 质变**仅当已拥有对应武器且本局尚未取得该词条时进池**，不 roll 品质。
- 质变入池门控：每次生成候选以 **0.5%** 概率开放质变候选集合，通过门控仍需参与后续抽取，不等于必出质变卡。
- 通用候选权重为 **10**；专属权重为 `clamp(1 + floor(Luck / 40), 1, 5)`；通过门控的质变候选权重为 **10**。幸运不改变质变门控概率。归属 `EmberChoicePool.Build` / `WeightForSpecial`。
- **质变无前置条件**（不需要先拿专属）。

### 4.10 临时 Buff 与 Debuff

Buff 与 Debuff 统一使用 `BuffConfig`、`Buff`、`BuffManager`；配置归 `Assets/Scripts/Core/Buffs/EmberBuffCatalog.cs`，掉落与技能频率归 `LevelConfig`。

| 效果 / 参数 | 当前值与规则 |
|---|---|
| 增伤 `power` | 玩家造成的伤害 +30%，持续 8 秒 |
| 疾行 `haste` | 玩家移动速度 +30%，持续 8 秒 |
| 迟缓 `slow` | 玩家移动速度 -25%，持续 3 秒，标记为 Debuff |
| Buff 掉落概率 | 普通敌人最终死亡 12%，词缀怪 25%，Boss 100%；分裂子体不掉落，重生接管不掉落 |
| Buff 掉落种类 | 增伤 / 疾行等概率二选一；与治疗掉落独立判定，可同时掉落，不替代治疗 |
| 掉落存留与拾取 | 与治疗物共用 §3.7 的寿命、吸附和总容量；满血可拾取；绿色药瓶为治疗，橙色火种护符为增伤，青色风羽为疾行 |
| 迟缓技能 | 暗烛射手每第 3 次射击释放迟缓弹；青色预警线与弹体，仍造成原射手伤害，可被拦截 |
| 技能命中规则 | 迟缓弹命中且玩家原本不在无敌帧时施加；致死后不施加。护盾吸收伤害仍算命中；普通暗弹不施加 |
| 同类重复施加 | 相同 Id 刷新到完整持续时间，不叠加强度和层数；配置在运行期间不可变，同 Id 使用同一共享配置 |
| 属性合成 | 同属性的临时修正加算：`倍率 = 1 + 有效 Buff 的 Bonus 之和`；移速倍率最低 0.25，伤害倍率最低 0 |
| 临时伤害作用点 | 在 `EmberCombatDamage.Apply` 的实际命中时乘一次 Buff 伤害倍率，再走敌方减伤；覆盖所有武器和共享燃地，已有弹体按命中时效果结算 |
| 生命周期 | 只在 Playing 阶段按游戏时间计时，随倍速缩放；暂停和选卡冻结，普通换波保留，退出和新局清空 |
| 界面 | 顶部 HUD 下方横排小图标：火种护符为增伤、风羽为疾行、紫色靴子与下箭头为迟缓；外围环按 `剩余时间 / 完整时长` 减少，下面显示向上取整的秒数。同类刷新时环和秒数恢复。获得效果时在角色上方显示「效果名 + 正负百分比」浮字，刷新加「刷新」前缀；浮字向上淡出，不使用大底板。全部控件复用 Prefab |

临时增伤独立于选卡构筑，不改写单武器攻击力、攻速或 `DamageAmp`。到期移除 Buff 后重新汇总倍率，不对基础属性进行反向乘除。治疗为即时效果，仍走生命结算；共享燃地仍是区域伤害。

## 5. 结算与计分

- 余烬与击杀只加 Score：普通 **1**、词缀怪 **3**、Boss **30**、分裂子体 **0**（子体仍计入击杀统计）。
- 击杀直接计分，不生成可拾取余烬；治疗掉落按 §4.4 处理。
- 最终分 = 原始 Score（`ScoreMult ≡ 1.0`）。
- 结算屏显示本局难度、征程长度、波数、时间、击杀、Score。

## 6. 单局规则边界

成长与构筑只在本局生效；选卡由清波触发，Boss 出场由波次驱动，计分按 §5 处理。

### 参数维护边界

玩法与可调表现参数的完整数值表只在本文件维护；模块架构使用参数名、计算关系与源码归属，不并列维护另一份调参表。类型数量、Id、资产切片格数与接口分支条件属于结构说明，可在模块文档中出现。新增或修改规则应同步需求与源码，历史调档过程放归档。

粒子容量为 **120**（`EmberEffects`）；共享燃地与暗弹容量分别见 §4.9、§3.7。加载页正常路径最短展示 **5 秒**，进度节点依次为 **0.15 → 0.55 → 1.0**（`EmberIntro.Load`）；字体创建失败时走较短的兜底路径。这些是当前实现定义的表现默认值。

### 源码维护与工程交付

生命规则与选卡推进不得读取场景句柄或创建音频单例。构筑在开局时以所选武器和槽位初始化一次；普通卡池与刷新不接收无效波次参数。武器身份与基础文案集中在 `EmberWeaponCatalog`；基础参数与升级增量集中在 `EmberWeaponTuning`。卡牌预览应与实际效果一致。共享燃地由独立效果模块管理。死亡结算须同时更新整局击杀与波次记录。提交物包含可重新导入的工程、实际资源、源码与 .meta，不能只有可执行程序。

### UI 复用与状态栏呈现

菜单、开局选择、设置与升级面板复用 Prefab 中的控件，重复打开不重建整个界面。刷新、关闭和再次打开须正确重置交互状态与业务回调，不改变选项规则和设置语义。战斗 HUD 保留生命、护盾、波次、武器、幸运和暂停功能，通过细条与独立文字行改善层次与可读性。EmberIntro 绑定 IntroRoot 已有控件并推进加载；校验字体后才显示加载页，加载就绪后接受继续输入并隐藏视图，不销毁 Prefab 实例。

运行时不回落到代码创建控件；缺少面板引用或缓存容量不足时报配置错误。控件工厂与旧快照补建仅在 Editor 中运行。HUD 的生命/护盾/构筑/击杀文字随对应值变化更新，时间按显示秒更新；波次文案只有一个写入点，内容和原展示一致。
