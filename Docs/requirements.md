# 烬灯行者（EmberlightWandere）需求文档

> 本文件是**产品行为、约束与数值的唯一权威来源**。
> 架构文档只描述"怎么实现"，不复制这里的数值；发现数值不一致时以本文件为准。
> 最后核对：2026-09-14（已对照 `Assets/Scripts` 代码逐项验证）

## 1. 产品定位与范围

一盏灯芯走在长夜里。虚拟摇杆移动、武器自动开火、清波选卡变强，撑过全部波次即为通关。

| 项 | 内容 |
|----|------|
| 平台 | Android（竖屏）+ Editor 内试玩 |
| 单局时长 | 25 波（推荐）或 50 波 |
| 视角 | 2D 俯视，正交相机，固定竖屏构图 |
| 美术 | 简笔画（doodle）风格，暖色灯芯调；占位美术允许程序生成 |
| 付费 / 联网 | 无 |

### 本轮明确不做

- 局外成长（灯油、灯铺、图鉴、成就、解锁树）——**已删除**，见 §6
- 关卡制、多地图、多角色
- 联网、排行榜、云存档
- 伤害数字飘字
- 3D 空间音、混音器
- 真实感美术替换（占位美术可长期保留）

## 2. 单局主循环

```text
营地（主菜单）
  → 选征程长度（25 / 50 波）
  → 选难度（休闲 / 标准 / 困难）
  → 选武器槽位上限 N（1–5，默认 2）
  → 单选 1 把起始武器（整库翻页，必须点选）
  → 战斗：逐波清怪 → 清波选卡 → 下一波
  → 每 10 波阶段 Boss；最后 1 波最终 Boss
  → 最终 Boss 死亡 = 通关；生命归零 = 失败
  → 结算（显示本局难度、长度、波数、时间、击杀、Score）
```

**开局不可跳过**：必须选 N 并单选 1 把武器；异常回落为「火球 ×1 + N=2」。

## 3. 局内规则

### 3.1 波次

| 项 | 规则 |
|----|------|
| 波数 | 25 或 50 |
| 第 1–5 波配额 | 12 / 18 / 24 / 30 / 36 |
| 第 6 波起配额 | `min(70, 36 + 2×(wave−5))` |
| 配额修正 | 乘难度 `CountMultiplier` 后取整，下限 1 |
| 刷怪间隔（第 1–5 波） | 0.90 / 0.75 / 0.60 / 0.48 / 0.36 秒 |
| 刷怪间隔（第 6 波起） | `max(0.22, 0.36 − (wave−5)×0.006)` 秒 |
| 间隔修正 | 乘难度 `IntervalMultiplier`，下限 0.14 秒 |
| 清波条件 | 本波配额刷完 **且** 场上敌人为 0 |
| 同时存在敌人上限 | 150 |

### 3.2 精英与 Boss

| 项 | 规则 |
|----|------|
| 精英挑战波 | 每 5 波，且不是 Boss 波 |
| 阶段 Boss 波 | 每 10 波 |
| 最终 Boss 波 | 第 25 或第 50 波 |
| 阶段 Boss 血量 | `(1600 + wave×100) × HealthMultiplier` |
| 最终 Boss 血量 | 6000（25 波）/ 10000（50 波），再乘 `HealthMultiplier` |
| 暗弹齐射 | 第 20 波起加入，带 1 秒预警；随阶段增加弹数与暗焰落点 |
| 半血狂怒 | 保留 |

### 3.3 难度倍率

> **权威值**。来源：`Assets/Scripts/Core/LevelConfig.cs` —— 2026-09-14「全难度怪血 /2」。

| 难度 | 血量 `HealthMultiplier` | 敌方伤害 `DamageMultiplier` | 刷怪配额 `CountMultiplier` | 刷怪间隔 `IntervalMultiplier` | 词缀概率 `AffixMultiplier` |
|------|------:|------:|------:|------:|------:|
| 休闲 Casual | **0.25** | 0.70 | 0.85 | 1.15 | 0.70 |
| 标准 Standard | **0.5** | 1.00 | 1.00 | 1.00 | 1.00 |
| 困难 Hard | **0.675** | 1.30 | 1.20 | 0.88 | 1.25 |

- 敌方伤害倍率在 `HurtPlayer` **统一应用一次**，覆盖接触、射手、爆炸、灼热与 Boss。
- 每种难度**每局初始生命 100**，无任何永久加成。
- ⚠️ 早期文档里的 `0.75 / 1 / 1.35` 与「休闲 0.5」均为**已被本次 /2 覆盖的历史值**，不要再引用。

### 3.4 敌人血量

| 种类 | 公式（未乘 `HealthMultiplier`） |
|------|--------------------------------|
| 普通 trash | `16 + wave×6` |
| 高血 / 盾卫 tough | `40 + wave×10` |
| 暗烛射手 | `trash × 0.8` |
| 烬胎（母） | `tough × 0.6` |
| 烬虫（子） | `trash × 0.25` |
| 铁灯卫 | `tough × 1.2` |
| 引线虫 | `trash × 0.6` |

### 3.5 精英词缀

| 词缀 | 效果 |
|------|------|
| 灼热 | 2 单位内每秒 2 点伤害，多圈**不叠加** |
| 疾风 | 每 3 秒爆发速度 ×1.8，持续 1 秒 |
| 重生 | 死亡后读条 2 秒，以 40% 生命复活**一次** |

- 概率：第 3 波起 12%，第 5 波起 18%，之后每波 +0.3%，**封顶 50%**（均乘 `AffixMultiplier`）。
- 第 2 波及以前**不出词缀**；精英挑战波的强制小队**不**走随机词缀。
- 词缀怪余烬奖励 ×3。

### 3.6 选卡次数

| 波次 | 每次清波选卡次数 |
|------|------------------|
| 第 1–10 波 | 1 次 |
| 第 11 波起 | 每两波（偶数波）1 次 |
| 阶段 Boss 波 | 在上述基础上**额外 +1**（即连续选 2 次） |
| 最终波 | 直接结算，不选卡 |

- 固定选卡总数：**25 波 = 18 次；50 波 = 32 次**（Boss 波的额外次数已计入）。
- 每次选卡各自允许一次「获得新武器后的补偿选卡」，补选不消耗后续固定次数，且**不连锁**。

## 4. 构筑与卡池（Gods-Select-v3）

### 4.1 槽位与开局

| 项 | 规则 |
|----|------|
| 槽位上限 N | 1–5，默认 **2** |
| 开局武器数 | **恒为 1**（禁止开局一次填满 N 槽） |
| 空位数 | `N − 1` |
| 满槽后 | 池中**不再出现**「新武器」 |
| 口径 | N 少 = 更稳、更容易成型；N 多 = 更花、更容易歪。**N 不是难度惩罚** |
| ScoreMult | **恒为 1.0**，不做随 N 变化的分数倍率 |

### 4.2 武器花名册（占槽）

| Id | 武器 | 说明 |
|----|------|------|
| 13 | 火球 | 自动锁定最近可见敌人 |
| 14 | 环火 | 环绕火种，接触伤害 |
| 15 | 燃地 | 沿路留火，踩踏掉血 |
| 10 | 穿透火矢 | **基本静止时才开火**，一箭穿多 |
| 11 | 回旋烬蝶 | 去程 / 回程两段均可命中 |
| 12 | 天降火雨 | 预警圈后范围伤害 |

- 冲击波（Pulse）**不占槽**，本版无选卡入口（`WavePower` 恒为 0，实际不可用）。

### 4.3 出卡规则

- 候选张数 = `3 + 空位数`，从中**选 1**。
- 基础 3 张来自「通用 / 专属 / 质变」，**同屏唯一键为 `(词条Id, WeaponId)`**：
  - ✅ 可同屏：`火球·攻击力` + `环火·攻击力` + `全体伤害增幅`
  - ❌ 禁止：两张 `火球·攻击力`；三张 `全体伤害增幅`
- 额外张：仅当槽未满时出现的**未拥有武器**，数量 = 空位数。
- 选中**新武器**后立刻补发**一次**选卡（不推进波次）。
- 整局**免费刷新 2 次**；**禁止**出现「+刷新次数」类词条。

### 4.4 通用词条数值（按幸运 roll 品质）

| 词条 | Id | 青铜 | 白银 | 黄金 | 钻石 |
|------|----|-----:|-----:|-----:|-----:|
| 攻击力（**单武器**） | 0 | +10% | +20% | +30% | +40% |
| 攻速（**单武器**） | 1 | +10% | +20% | +30% | +50% |
| 幸运（全局） | 2 | +25 | +50 | +75 | +125 |
| 全体伤害增幅（**全局**） | 3 | +5% | +10% | +15% | +25% |
| 护盾（全局） | 4 | 250 | 500 | 750 | 1250 |

- **攻击力 / 攻速只作用于对应已有武器**，不是全局；不另开全局攻击力（防早期伤害膨胀）。
- **全体伤害增幅**为全局乘区：`伤害 = 武器基伤 × (1 + 单武器攻击力) × (1 + DamageAmp)`。
- 幸运上限 **120**，只影响品质权重与专属/质变进池率。
- 护盾：选择后立即加算可叠加，受伤时**先乘难度倍率、再扣护盾**，溢出部分扣生命；护盾不自动恢复、新局清零、无局外存档。
- 回血道具：每个回复 20 HP（不超上限），普通敌人最终死亡 8%、带词缀敌人 20%、Boss 100% 掉落；分裂子体不掉落；重生读条前不算最终死亡。

### 4.5 幸运 → 品质权重

> **权威值**。来源：`Assets/Scripts/Core/EmberRarity.cs::WeightsForLuck`（2026-09-13 高品质出率下调）。

| 幸运 | 青铜 | 白银 | 黄金 | 钻石 |
|-----:|-----:|-----:|-----:|-----:|
| 0 | **72** | **22** | **5** | **1** |
| 60 | **58** | **28** | **11** | **3** |
| 120 | **45** | **32** | **18** | **5** |

中间线性插值。**旧的波次稀有度门控（20/40/65/90 或 70-25-5-0 那套）不再用于通用词条**（`Roll(random, wave)` 仅保留给其它系统）。

> ⚠️ 早期文档中残留的 `60/28/10/2` 表是**已被下调覆盖的旧值**，不要引用。

### 4.6 专属（固定黄金）与质变（固定钻石）

| 武器 | 专属（金，Id 30–35） | 质变（钻，Id 20–25） |
|------|----------------------|----------------------|
| 火球 | 连发：额外火球 +1 | 燎原：体积 ×1.5、伤害 ×1.25、命中留燃地 |
| 环火 | 添薪：环绕 +1 | 日冕：半径 / 转速 / DPS 上调 + 灼烧拖尾（单球 DPS 75） |
| 燃地 | 延烧：拖尾更长更烫 | 火海：身周持续火圈 |
| 穿透火矢 | 贯穿：穿透上限 +1 | 穿杨：命中分裂一小支（伤害 ×0.45） |
| 回旋烬蝶 | 回马：往返各多一段结算 | 折返无尽：多一个来回 |
| 天降火雨 | 多落点：+1 落点 | 天火：圈更大、伤更高（约 +10%） |

- 专属 / 质变**仅当已拥有对应武器时进池**，不 roll 品质。
- **质变无前置条件**（不需要先拿专属）。

### 4.7 词条 Id 分区

| 区间 | 类型 |
|------|------|
| 0–4 | 通用（攻击力 / 攻速 / 幸运 / 增幅 / 护盾） |
| 10–19 | 武器 |
| 20–29 | 质变 |
| 30–39 | 专属 |

> 旧通用 Id 5–9（拾取 / 移速 / 生命 / 冲击波 / 治疗）**已退出选卡池**。

## 5. 结算与计分

- 余烬与击杀只加 Score：普通 **1**、词缀怪 **3**、Boss **30**、分裂子体 **0**（子体仍计入击杀统计）。
- **死亡掉落已删除**：不再生成可拾取余烬；`PickupBonus` 停用。
- 最终分 = 原始 Score（`ScoreMult ≡ 1.0`）。
- 结算屏显示本局难度、征程长度、波数、时间、击杀、Score。

## 7. 技术约束

| 项 | 值 |
|----|----|
| Unity | 2022.3.62f3 |
| 主场景 | `Assets/Scenes/Emberlight.unity`（唯一启用场景） |
| 命名空间 | `Emberlight`；编辑器为 `Emberlight.Editor` |
| 渲染 | Built-in；正交相机 |
| UI | uGUI + TextMeshProUGUI；竖屏 540×960 锚点 |
| 输入 | 旧版 Input（`Input.GetKeyDown` 等）；虚拟摇杆为自绘 |
| 中文 | `EmberFonts.CreateChinese()` 运行时从 `Fonts/NotoSansCJKsc-Regular.otf` 烘动态 SDF 图集 |
| 帧率 | `targetFrameRate = 60`、`vSyncCount = 0`（移动端默认封顶 30，必须显式设置） |
| 程序集 | 当前**无 `.asmdef`**，全部编译进 `Assembly-CSharp` / `Assembly-CSharp-Editor` |
| 包名 / 版本 | `com.Emberlight.Wanderer` / `0.1.0`（versionCode 1） |
| 最低 / 目标 API | 24 / 35；IL2CPP；ARM64 + ARMv7 |

> ⚠️ **中文字体预烘是已知雷区**：两次尝试都导致 UI 全崩（详见 `architecture/07-art-presentation.md`）。`EmberFonts` **固定走动态图集**，不要改回预烘。

### UI 复用与状态栏呈现（2026-09-15）

设置与升级面板应复用运行时创建的控件，重复打开不重建整个界面。刷新、关闭和再次打开须正确重置交互状态，不改变选项规则和设置语义。战斗 HUD 保留生命、护盾、波次、武器、幸运和暂停功能，通过细条与独立文字行改善层次与可读性。


## 8. 验收口径

| 类别 | 定义 |
|------|------|
| **已验证** | 实际运行且通过的检查（附命令与结果） |
| **不适用** | 经说明理由后无需执行的检查（记 `N/A` + 理由，不算未验证） |
| **待人工验收** | 手感、审美、可读性、真机表现等必须由人在设备上判断的项 |
| **未验证** | 因环境、资源或权限无法执行的检查 |

- 通关判定：最终 Boss 死亡 = 胜；生命归零 = 负。
- 手感 / 平衡 / 音画观感的最终验收人为 **jack**。
