## 通用词条稀有度（Gods-Select-v3 · 幸运权重）
| 稀有度 | G-ATK / G-AS | G-LUCK | G-AMP |
|--------|--------------|--------|-------|
| 青铜   | +10%         | +25    | +5%   |
| 白银   | +20%         | +50    | +10%  |
| 黄金   | +30%         | +75    | +15%  |
| 钻石   | +40%         | +125   | +25%  |

幸运 → 品质权重（线性插值关键点）：
| 幸运 | 铜 / 银 / 金 / 钻 |
|------|-------------------|
| 0    | 60 / 28 / 10 / 2 |
| 60   | 45 / 30 / 18 / 7 |
| 120  | 30 / 28 / 28 / 14 |

- 幸运上限 **120**；只影响品质权重与专属/质变进池率。
- **旧波次稀有度门控不再用于通用词条**（`Roll(wave)` 仍保留给其它系统）。
- 旧通用 0–9（ExtraShots/Orbits/Trail/移速/生命/拾取/冲击波/治疗）**退出选卡池**。
- ATK/AS 加算全局；AMP 另乘全体武器：`DamageMul = (1+DamageBonus)*(1+DamageAmp)`。
- 余烬只加 Score；结算原始 Score（ScoreMult 恒 1.0）。

## 遗留 Magnitude（非通用出卡）
铜/银/金/钻 = 0.20 / 0.40 / 0.65 / 0.90；CountBonus 1/2/2/3。波次门控仍在 `Roll(random, wave)`。
