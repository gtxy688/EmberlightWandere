## 稀有度规则（Difficulty-Waves-v2；v1 作废）
| 稀有度 | 百分比类幅度 | CountBonus（额外弹/环绕） |
|--------|--------------|---------------------------|
| 青铜   | **+20%**     | +1                        |
| 白银   | **+40%**     | +2                        |
| 黄金   | **+65%**     | +2                        |
| 钻石   | **+90%**     | +3                        |

### 波次权重门控（`EmberRarityUtil.Roll(random, waveCleared)`）
| Wave | 铜 / 银 / 金 / 钻 |
|------|-------------------|
| 1–2  | 70 / 25 / 5 / **0** |
| 3–4  | 55 / 30 / 12 / 3 |
| 5+   | 50 / 28 / 15 / 7 |

说明：
- **无 XP / 等级制**；升级仅 WaveClear 三选一（最多 5 次，Wave1–5）。
- 余烬只加 Score；青铜/白银/黄金/钻石仅作稀有度。
- 百分比类（攻速/伤害/移速/拖尾/冲击波等）用 Magnitude：`0.20 / 0.40 / 0.65 / 0.90`。
- 拾取范围：`mag * 2`（可附带轻度分数效率）；生命上限：`100 * mag`（+20 / +40 / +65 / +90 点）。
- 治愈：20 / 30 / 40 / 50。
- **CountBonus 维持 1/2/2/3**（ExtraShots / Orbits）。
