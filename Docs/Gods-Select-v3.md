# 选卡与词条 · 诸神对齐（Gods-Select-v3）

> 状态：现行待改开局（2026-09-13）· jack 纠正：开局一次只选 1 把武器  
> **取代** `Gods-Select-v2.md` / `Gods-Select-v1.md`（流程保留精神，出卡与词条按本文）  
> 原则：学诸神流程；通用词条收窄；不抄阳光点地；安卓最后  
> `Enemy-Variety-v1` 继续暂停至本规格验收

## 目标
- 开局只选 1 把武器 + 槽位上限 N；其余武器靠局内选卡塞进空槽；少槽更好成型。
- 通用词条只做：攻击力、幸运、伤害增幅。（含全局攻速（jack 2026-09-13 加回）：铜银金钻 +10/+20/+30/+50%。
- 每武器 1 黄金专属 + 1 钻石质变；质变无前置条件（有武器 + 幸运够就能刷到）。

## 1. 开局（jack 纠正）

> **禁止**开局一次选满 N 把。对标诸神：先选 1 株，再定本局可用数量；多出来的靠局内词条拿。

1. 选本局槽位上限 **N = 1…5**（默认 **2**）。少=稳/易成型；多=花/易歪。N 只是上限，不是开局必填数。  
2. **整库翻页只选 1 把**开局武器（花名册任选其一）→ 开战时 `已有武器=1`，空位=`N-1`。  
3. 异常/跳过回落：火球 ×1、N=2。  
4. **不做** ScoreMult、稀有度偏置表。

### 武器花名册（占槽）
火球、环火、燃地、穿透火矢、回旋烬蝶、天降火雨。  
冲击波：**不占槽**，若保留则仅作后续专属/Stat 外系统（本版可不进选卡）。

### 开局给予（仅对选中的那 1 把）
| 武器 | 基线 |
|------|------|
| 火球 | Owned Basic，默认火力 |
| 环火 | Owned Orbit，Orbits=1 |
| 燃地 | Owned Trail，TrailPower=0.20 |
| 穿透/烬蝶/火雨 | Owned 对应，数值沿用 Build-Depth |

## 2. 局内出卡
- 清波 → 选卡 → 下一波；Wave6 Boss。一波一次。  
- 候选张数：`3 + max(0, N - 已有武器数)`，**从中选 1**。  
- 前 3 张：通用 / 专属 / 质变（见下）。  
- 额外张：仅当槽未满时出现的**未拥有武器**；数量=空位数；**不占**前 3 的词条种类名额。  
- **同屏每种词条最多 1 张**（不能三张都是攻击力）。  
- 选中**新武器**后：立刻再发 **一次**选卡（补偿）。  
- 整局 **2 次免费刷新**；**禁止**「+刷新次数」类词条。

## 3. 通用词条（会 roll 品质）

> jack 纠正：**全局没有攻速加成**。通用池：攻击力 / 攻速 / 幸运 / 伤害增幅（+护盾若仍在池）。

| Id 建议 | 名称 | 铜 | 银 | 金 | 钻 |
|---------|------|----|----|----|-----|
| G-ATK | 攻击力 | +10 | +20 | +30 | +40 |
| G-LUCK | 幸运 | +25 | +50 | +75 | +125 |
| G-AMP | 伤害增幅 | +5% | +10% | +15% | +25% |

- 攻击力：加算到全局（再参与各武器公式）。  
- 伤害增幅：另乘一档（全体武器）。  
- 幸运：上限 **120**；只影响品质权重与专属/质变进池率。  
- | G-AS | 攻速 | +10% | +20% | +30% | +50% |  
- **旧通用** ExtraShots/Orbits/Trail/移速/生命/拾取/冲击波/治疗：**退出通用池**（弹数等改走武器专属）。

## 4. 专属（固定黄金）/ 质变（固定钻石）
- 仅当**已拥有**对应武器时进池。  
- 质变：**无**层数/先专属等条件；幸运高则更容易出现在 3 张里。  
- 专属/质变不 roll 品质。

| 武器 | 专属（金） | 质变（钻） |
|------|------------|------------|
| 火球 | 连发：额外火球 +2 | 燎原：体积/伤害×1.5，命中留燃地 |
| 环火 | 添薪：环绕 +2 | 日冕：半径/转速/DPS 上台 + 灼烧拖尾 |
| 燃地 | 延烧：拖尾更长更烫 | 火海：身周持续火圈 |
| 穿透火矢 | 贯穿：穿透目标数 + | 穿杨：命中分裂一小支 |
| 回旋烬蝶 | 回马：往返各多一段结算 | 折返无尽：多一个来回 |
| 天降火雨 | 多落点：+1 落点 | 天火：圈更大、伤更高 |

（旧 Build-Depth 进化条件表作废，以本表为准；Id 可复用 20/21 或重编号。）

## 5. 池优先级（实现用，少数字）
组「基础 3 张」时：在尚未出现的种类里抽——  
通用三选（攻/幸/增幅）+ 已有武器之专属/质变；幸运越高，专属/质变权重越高。  
再追加空位数量的新武器卡。  
不足 3 种时用尚未出现的通用补齐；保证总能选。

## 6. 边界
- 不抄阳光、点地、翻页大图鉴（开局武器库翻页可以有）。  
- 不做刷新词条、不做 ScoreMult。  
- 不改 Boss 波次配额除非验收需要。  
- Enemy-Variety 暂停。安卓最后。

## 7. 验收
1. 开局：先选 N，再整库翻页**只选 1 把**；默认 N=2；开战已有=1。  
2. 满槽（含 N=1）：出卡张数=3，无新武器；未满：`3+空位`。  
3. 同屏无重复词条种类。  
4. 选新武器 → 立即再选一次。  
5. 通用仅三种（攻/幸/增幅，无全局攻速）；专属金、质变钻；质变无条件。  
6. 幸运上限 120，品质权重表可测；2 次刷新可用且无刷新词条。  
7. 旧 0–9 通用不再出现在选卡里。

## 8. 落地顺序（可回退）
1. 数据：通用四词条 + 幸运/增幅；砍旧通用出池  
2. 出卡：`3+空位`、种类不重复、新武器补偿选卡、2 次刷新  
3. 开局 UI：N + 整库翻页**单选 1 把**；Begin 只激活这一把；勿再一次填满 N 槽  
4. 专属/质变六条线行为 + 进池规则  
5. Validate + Design/Rarity 文档同步

## 10. 实现备注（落地 · Gods-Select-v3）

- 通用 Id：`0` G-ATK / `2` G-LUCK / `3` G-AMP；**`1` G-AS 退出选卡池**（可留字段但不出卡、不加算全局攻速）；旧 4–9 仍退出选卡池。
- 武器占槽：`13` 火球 / `14` 环火 / `15` 燃地 / `10` 穿透 / `11` 烬蝶 / `12` 火雨；冲击波不占槽。
- 专属（金固定）`30–35`：连发 / 添薪 / 延燃 / 贯穿 / 回马 / 多落点。
- 质变（钻固定）`20–25`：燎原 / 日冕 / 火海 / 穿杨 / 折返不尽 / 天火；**无**专属前置。
- 开局：`ShowSlots` → `ShowRoster` **单选 1 把**；`ConfigureRun(int[] weapons={one}, N)`（weapons 长度恒为 1）；Skip=火球×1+N=2。**禁止**开局一次填满 N。
- 出卡：`3 + EmptySlots`；基础 3 为通用/专属/质变（同屏 Id 不重复）；额外张仅为未拥有武器。
- 新武器补偿：`Choose(..., out grantedNewWeapon)` → 立刻再 `OfferChoices` 一次（不推进波次）。
- 整局 `RefreshesRemaining=2`；`TryRefresh`；禁止刷新类词条。
- 幸运上限 120；`RollByLuck` 权重表；伤害 = 武器基伤 × `(1+DamageBonus)×(1+DamageAmp)`。
- UI API：`EmberGame.RefreshRemaining` / `LuckValue` / `CurrentOffers`；`EmberGodsSelectPanel.ShowRosterSelect`；升级面板刷新按钮。
- ScoreMult 恒 1.0；Enemy-Variety 仍暂停。
- Validate：`ValidateGodsSelect` + `ValidateBuildDepth` 覆盖 v3 验收点。
