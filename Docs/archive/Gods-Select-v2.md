# 选卡 · 杂交版流程（Gods-Select-v2）

> 状态：**作废**（2026-09-13）→ 见 Gods-Select-v3  
> **作废**：`Gods-Select-v1` 里以 Score 倍率、稀有度偏置、复杂权重表为主的「数值向」口径。  
> 参考：植物大战僵尸融合版「诸神：进化」——**开局定核心与卡组宽度，局内围着已有单位长**。  
> 原则（jack）：**完全按杂交版那套流程想**；**不要堆稀有度/幅度数值**；能复用现有升级/进化就复用。  
> 前置：清波强制三选一（`Difficulty-Waves-v2`）；武器实体基座（`Build-Depth-v1`）。  
> 暂停：`Enemy-Variety-v1` 至本规格验收。

## 一句话

开局先选「带谁打」和「本局最多带几样」→ 每清一波只在这些东西上升级/进化/偶尔塞新武器 → 满槽就别再塞新的。

## 1. 开局（进战斗前，两步）

### 1.1 选核心（必选）

三选一，对标诸神「选 1 株开局植物」：

| 核心 | 开局就有 |
|------|----------|
| 火球 | 基础火球 |
| 环火 | 环绕火种（能转就算启用） |
| 燃地 | 燃地拖尾（能烧地就算启用） |

- 必须点选；实现上可默认高亮火球，但要确认才开战。
- 冲击波：仍靠局内词条开，**不占槽、不当核心**。

### 1.2 选本局武器槽 N（1–5）

对标诸神「本局可用植物数量」。

| N | 玩家感受（口径） |
|---|------------------|
| 少 | **更简单、更稳**：池子贴着核心，不容易歪 |
| 多 | **更花、更容易歪**：分支多，容易摊薄 |

- 默认推荐 **N=2**。
- 核心占 1 个槽；`已有武器种数` 到 N 后，清波**不再出现「新武器」**，只出：升级已有 / 进化 / 通用强化。

> 不要再做：N 对应一整套 Score 倍率表、N≤2 偏金钻、少槽=高难度惩罚。通关分数有击杀就够；槽位只影响「好不好玩、歪不歪」，不当第二套数值系统。

## 2. 局内（清波三选一）

流程不变：清完 Wave → 停住 → 三选一 → 下一波；最后 Boss。

### 2.1 每张卡只做三类事（学诸神：升级已有 / 新单位 / 进化）

| 类型 | 意思 | 何时能出 |
|------|------|----------|
| 强化已有 | 你已经带的武器/核心再强一点（重复选=升级） | 常驻 |
| 新武器 | 多带一样（穿透 / 烬蝶 / 火雨等） | 未满槽，且别太早（W1 尽量别塞花活） |
| 进化 | 某条线质变（燎原 / 日冕…） | 条件够了、且这条线本局有 |

### 2.2 池子怎么偏（规则，少写数字）

1. **先看你身上有什么** → 优先给「强化已有 / 对应进化」  
2. **槽没满** → 偶尔给「新武器」  
3. **槽满了** → 禁止新武器  
4. 三张里尽量别重复；不够就塞通用强化（攻速/伤害/生命等现成 Stat），保证总能选

> 不要再维护一张「进化 8 / 升级 4 / Stat 2 / 新武器 1.2」必考权重表。实现可用简单优先级：进化（若可）> 升级已有 > 通用强化 > 新武器（若可）；抽 3 张不重复即可。

### 2.3 稀有度

- **先别动**现有铜银金钻表现（颜色/文案可以留）。  
- **本版目标不是调幅度**：不要借选卡改版再改 Magnitude / 波次稀有度门控。那是另一件事。  
- 进化卡外观继续「特殊/钻石风」即可，不必再写概率公式。

## 4. 验收（手感向，少断言数字）

1. 开局必须：选核心 → 选 N → 才进 Wave1。  
2. N=1：整局几乎只在核心上长，清波很难刷出第三种武器。  
3. N=5：明显更能塞多种武器，也更容易「什么都沾一点」。  
4. 满槽后三选一里看不到新武器。  
5. 进化仍要「这条线有了 + 条件够了」才出现；选了才变。  
6. 不要出现：为了选卡又改一版怪物血量 / 又改一版稀有度幅度表。

## 5. 落地顺序

1. 去掉（或旁路）v1 数值向：ScoreMult、N 稀有度偏置  
2. 开局两步只服务流程：核心 + N；满槽禁新武器  
3. 清波池改为「有什么推什么」的简单优先级（§2.2）  
4. HUD：`武器 已有/N` 即可  
5. 文档：本篇为准；`Gods-Select-v1` 顶标注作废；Design 改指向

## 7. 实现备注（落地）

- 核心武器 Id：`WeaponBasic=13` / `WeaponOrbit=14` / `WeaponTrail=15`；冲击波仍 Stat Id8，不占槽。
- `RunProgress.ConfigureRun(core, N)`：只授予所选核心；默认构造 = 火球 + N=2；开局两步 UI 须确认。
- **ScoreMult 恒为 1.0**；`FinalScore()` = 原始 Score；结算屏不再显示 ×N 倍率。
- **无** N 稀有度偏置；Magnitude / 波次稀有度门控 **未改**（仍 Difficulty-Waves-v2）。
- `Choices`：**简单优先级填充**（无权重表）Evolution → Owned 升级 → Stat → New（仅 `OwnedWeapons.Count < N`）；同 offer 不重复；不足用 Stat 补齐至 3。
- 槽满 → 禁止 New Weapon；W1 禁止 Id10–12；New 在合格池内随机（核心与 Id10–12 同池）。
- HUD：`武器 Owned/N`；`Enemy-Variety-v1` 仍暂停。
- Validate：`ValidateGodsSelect`（core+N 默认、满槽无新、ScoreMult=1、优先级池、进化需 Owned）。
