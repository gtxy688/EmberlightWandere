# 选卡改版 · 诸神式开局与槽位（Gods-Select-v1）

> 状态：**作废（数值向）** → 见 `Gods-Select-v3.md`（现行）；v2 亦作废
> （下文仅存档，勿再实现 ScoreMult/偏置表）

> 暂停：`Enemy-Variety-v1.md`（批次二）→ **本规格落地前不开工**
> 衔接：`EmberGame` / `RunProgress` / `EmberRarity` / `EmberCombat` / `EmberUpgradePanel` / `EmberHud` / `EmberChecks`

## 目标
- 开局先定「核心武器」与「本局武器槽位数 N」，每局 build 路线分化。
- 清波三选一改为**上下文加权**：已有武器升级/进化权重升高；新武器更稀、更晚；通用 Stat 仍可出。
- 进化条件继续按 `Build-Depth-v1`；与 Id10–12、20–21 衔接清晰。
- 可运行、可回退；安卓仍最后。

## 规则

### 1. 开局选核心武器（三选一）
| 选项 | 对应武器 | 开局给予 |
|------|----------|----------|
| 火球 | Basic（现有火球） | `OwnedWeapons` + Basic；火力按现网默认（冷却/伤害不变） |
| 环火 | Orbit | `OwnedWeapons` + Orbit；基线 `Orbits = 1`（可被后续 CountBonus 叠） |
| 燃地 | Trail | `OwnedWeapons` + Trail；基线 `TrailPower = 0.20`（约等于旧青铜拖尾一档） |

- **不选默认：火球**（最稳、与旧局手感一致）。UI 须点选确认；若实现超时/跳过，回落火球。
- 冲击波（Pulse）**不占武器槽**：仍由 Stat Id8 `WavePower` 开门，不算「核心/槽位武器」。
- 未选中的核心武器：本局视为**未拥有**；要获得须走「新武器」卡（且受槽位 N 限制）。火球/环火/燃地互为可解锁武器（解锁波：火球 W1 即可作新武器；环火 W2+；燃地 W2+——与「新武器更晚」一致，核心已选则不受此锁）。

### 2. 开局选武器槽位数 N（1–5）
- N = 本局最多拥有的**不同武器**种数（核心已占 1 槽）。
- `OwnedWeapons.Count` 达到 N 后：池中**不再出现**「新武器」；只出已有武器升级 / 合格进化 / Stat。
- **不选默认：N = 2**（偏稳，仍能摸一把副武器）。

> **口径（jack）**：槽位**少 = 更简单、更稳、不容易歪词条**；槽位**多 = 更花、更容易歪构筑**。  
> 禁止再写「N=1 最难」。少槽是稳健档，多槽是高自由/高失误档。

| N | 定位 | 驾驭难度 | 结算 Score | 说明 |
|---|------|----------|------------|------|
| 1 | 专精稳健 | **最低** | ×**1.00** | 池子几乎贴核心，极难歪 |
| 2 | 双核（推荐） | 低 | ×**1.05** | 默认可带 1 把副武器 |
| 3 | 基准 | 中 | ×**1.10** | 有一定分支空间 |
| 4 | 宽构筑 | 较高 | ×**1.25** | 易摊薄，通关奖励略高 |
| 5 | 武器库 | **最高** | ×**1.40** | 最易歪；奖励补偿「玩好更难」 |

- Score 倍率奖励的是「在更易歪的槽位下仍通关」，**不是**「少槽吃惩罚」。不改杂兵/Boss 血量表。
- N=1 **不再**给金/钻稀有度偏置（那会把稳健档做成刷稀有度）。

### 3. 清波仍强制三选一（上下文池）
- 流程不变：Wave1–5 清波 → 强制三选一 → 下一波；Wave6 Boss。
- 每 offer 抽 3、同 offer 不重复；**加权不放回**，权重改为：

| 候选 | 权重 | 条件 |
|------|------|------|
| Evolution | **8** | 条件已满足、未进化、且对应基础武器已拥有 |
| Owned Weapon 升级 | **4** | 已在 `OwnedWeapons` |
| Stat（0–9） | **2** | 常驻 |
| New Weapon | **1.2** | 未拥有、解锁波已到、且 `OwnedWeapons.Count < N` |

- 相对 Build-Depth-v1：Evolution / 已有升级升高；新武器 **3→1.2** 且受 N 门控。
- W1 清波：允许 Stat +（若槽未满）核心以外的新武器按上表；**不必**再「W1 仅 Stat」——开局已选核心，W1 可开始分化。若实现要保教学，可 W1 禁止 Id10–12（穿透等），仍允许另一核心武器作为 New。
- 兜底：候选不足 3 → Stat 补齐，绝不空选。
- 稀有度：Stat / 武器卡仍 `Roll(random, waveCleared)`（v2 幅度与波次门控）；进化卡**固定钻石**。

### 4. 进化与 Id10–12 / 20–21 衔接
- **条件原文不改**（Build-Depth-v1）：
  - Id20 燎原：`DamageBonus ≥ 1.0` 且 `TrailPower ≥ 0.4`；且 **已拥有 Basic（火球）**
  - Id21 日冕：`Orbits ≥ 5` 且 `AttackSpeedBonus ≥ 0.8`；且 **已拥有 Orbit（环火）**
- Id10 穿透火矢 / Id11 回旋烬蝶 / Id12 天降火雨：仍占武器槽；解锁波仍 W2 / W3 / W4；选「新武器」才入 `OwnedWeapons`。
- 进化是替换已有武器形态，**不另占槽**；选后从池移除（已进化不再出）。
- 专精提示：N=1 选火球 → 主走 Stat 伤害/拖尾冲燎原；N=1 选环火 → 叠 Orbits/攻速冲日冕；N=1 选燃地 → 无专属进化（本版不加第三进化），靠拖尾+Stat 续航，避免本版扩 Id。

### 5. 开局 UI 流程（局前，非清波卡）
1. 主菜单「开始」→ **核心武器三选一**（默认高亮火球）→ 确认  
2. → **槽位 N = 1…5**（默认 2）→ 确认  
3. → 进入 Wave1 Playing  

- 不用阳光、不点地、不翻页图鉴；两屏（或一屏两步）即可。
- HUD：显示当前 `武器数/N`（如 `2/3`）；Score 结算乘 N 倍率。

## 边界
- 不抄诸神：阳光经济、点地种升级、大翻页词条库、植物冷却格子。
- 不改 Wave 配额 / Boss 2200 / 无 XP（仍 v2）。
- 本版不新增进化 Id、不改 Id10–12 数值表（除非实现发现槽位逻辑必须的小修正）。
- `Enemy-Variety-v1` **暂停**至本规格验收通过。
- 安卓 / APK 仍最后。

## 验收（短）
1. 开局必经核心三选一 + N；跳过/异常回落 **火球 + N=2**。
2. 核心外武器未拥有时不 Tick；满 N 后清波三选一不再出现「新武器」。
3. 已有武器升级与进化权重明显高于新武器；进化条件仍按 Build-Depth，且缺基础武器时不出对应进化。
4. N=1 结算 Score×1.0；N=5 ×1.40；N=2 为默认；波次/Boss/无 XP 回归绿。
5. 无阳光点地、无翻页大库；主菜单→开局选→5 波选卡→Boss 闭环可跑。

## 落地顺序（每步可运行、可回退）
1. `RunProgress`：N + ScoreMult + 满槽禁新武器；`Choices` 权重表替换（Combat 仍可暂时开局挂满旧三件，先只验证池）
2. 开局核心三选一 + `Begin` 只激活核心（删默认三件套）
3. 开局选 N UI + HUD `武器数/N` + 结算倍率
4. 进化候选加「基础武器已拥有」断言；Validate 扩展
5. 同步 `Emberlight-Design.md` / `Rarity-and-TMP.md` 选卡节；标记 `Enemy-Variety-v1` 暂停
