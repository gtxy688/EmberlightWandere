# 局外成长系统（v1）

> 状态：**基础成长闭环已接入，待 jack 试玩**（2026-09-13）。本次范围为灯油、存档、灯铺三项永久属性；下文武器解锁、起始词条、图鉴、成就仍为后续策划。
> 衔接：`EmberGame` / `RunProgress` / `EmberMenuUi` / 新增 `EmberSave`
> 落地时须同步 `Emberlight-Design.md` 工程结构与原型范围。

## 目标

- 局内余烬 Score → 局外货币「灯油」，提供"再来一局"的钩子。
- JSON 存档（带版本号可迁移），替代 PlayerPrefs 承载全部局外数据。
- 主菜单扩展三块：灯铺（解锁树）、图鉴、成就。

## 1. 存档 `EmberSave`

- 路径：`Application.persistentDataPath/emberlight_save.json`，`saveVersion = 1`。
- 字段：`lampOil`、`unlocks[]`、`statNodes{id:level}`、`bestiary{kind:kills}`、`achievements[]`、`bestKills`、`bestScore`、`totalRuns`、`wins`。
- 读写全部收口在静态类 `EmberSave`；读取失败 / JSON 损坏 / 版本不符 → 备份旧档为 `.bak` 并重置新档，**绝不崩溃**。
- 现有 `PlayerPrefs "Emberlight.BestKills"` 首次启动迁移进存档后弃用。

## 2. 货币与结算

- **灯油 = floor(Score × 0.25) +（通关奖励 50）**。
- 一局基准：败北约 10–30，通关约 90–120（Score 150–300，含 Boss 掉落 30）。
- 结算页加一行「灯油 +N」，并显示累计余额。

## 3. 灯铺 · 解锁树

### a) 武器解锁（gating 卡牌池，衔接批次一）

| 节点 | 费用 | 效果 |
|------|------|------|
| 回旋烬蝶 | 80 | 未解锁时 id11 不入卡牌池 |
| 天降火雨 | 120 | 未解锁时 id12 不入卡牌池 |

- 穿透火矢与进化卡**默认开放**：保证新玩家 W2 就能摸到新武器、不锁构筑上限。

### b) 永久属性（各 3 档，费用 30 / 50 / 80 递增）

| 节点 | 每档效果 |
|------|----------|
| 火芯 | 基础伤害 +4% |
| 灯座 | 生命上限 +10 |
| 灯捻 | 移速 +2% |

### c) 起始词条槽（100 灯油）

- 开局前可从 5 个基础词条（id 0/1/2/6/7）选 1 个**青铜级**带入本局；开局界面多一个可选槽位，不选可直接开始。

### 数值基调

永久属性刻意保守（满档约 +12% 伤害）——局外成长是加分项，不能让卡牌构筑失去意义。

## 4. 图鉴

- 按敌人 kind（含词缀变体与 Boss）累计击杀数。
- 主菜单「图鉴」页：未击杀显示剪影；击杀 ≥1 显示名称与一句话简介；击杀 ≥30 显示完整描述。
- Boss「长夜守卫」条目首次通关解锁。

## 5. 成就（首批 6 个）

| 成就 | 条件 | 奖励灯油 |
|------|------|----------|
| 首次破晓 | 通关一次 | 50 |
| 百斩 | 单局击杀 ≥100 | 30 |
| 燎原之火 | 单局完成任意武器进化 | 40 |
| 游刃有余 | 单波全程不受击清完 | 30 |
| 夜话收集者 | 图鉴解锁全部普通敌人 | 50 |
| 长夜常客 | 累计开局 10 局 | 30 |

- 成就达成时局内/结算弹条提示，奖励自动入账。

## 6. UI

- 主菜单按钮：开始 / 灯铺 / 图鉴 / 成就（「试玩 Boss」保留在编辑器菜单，不进玩家 UI）。
- 灯铺：节点列表 + 费用 + 状态（可购 / 已购 / 灯油不足）。
- 结算页：灯油获得明细 + 新解锁/新成就弹条。

## 7. 接线要点

- `RunProgress` 构造后调用 `ApplyMeta(save)`：永久属性并入 baseline（如火芯 2 档 → `DamageBonus` 初值 0.08）；起始词条等价于开局自动 `Choose` 一次青铜卡。
- `EmberGame.End()`：结算灯油 → 写 bestiary/成就 → `EmberSave.Save()`，再显示结算页。
- 卡牌池查询 `EmberSave.unlocks` 过滤未解锁武器（`RunProgress.Choices` 增加解锁谓词参数，保持可测试）。

## 8. 验收

- 存档：写入 → 杀进程 → 读取一致；损坏 JSON 回退不崩；版本字段缺失/过旧走迁移路径。
- 经济：结算灯油公式断言；购买扣费与余额断言；余额不足不可购买。
- Gating：未解锁武器不出现在卡牌池；解锁后按批次一权重正常出现。
- 永久属性：`ApplyMeta` 后 baseline 断言；起始词条开局生效且不占 5 卡名额。
- 成就：6 个条件各自触发断言；奖励入账断言。
- 回归：无存档的新玩家流程与现状完全一致（含默认开放的穿透火矢）。

## 初版实装范围（2026-09-13）

- 加载页继续后进入营地主菜单，展示灯油、开局/通关次数、最高击杀/最高余烬；提供「提灯出发」「灯铺 · 永久成长」。
- 灯铺初版仅含火芯/灯座/灯捻，各 3 级，费用 30/50/80；每级分别 +4% 伤害、+10 生命上限、+2% 移速。成功购买即时保存，下次开局生效；新局以升级后的最大生命满血开始。不会反复叠加同一笔永久加成。
- 胜负结算灯油 = max(Score,0) 整除 4 + 胜利时 50。结算页显示兑换/通关明细、余额，支持再战、灯铺、营地。小于 4 余烬的失败局可获得 0 灯油。
- 每次实际进入战斗时登记 runId 并累加 totalRuns。只有胜负结算发灯油，主动退出/杀进程不会补发未结算局的奖励，不支持战斗中途续玩。
- JSON 路径为 Application.persistentDataPath/emberlight_save.json。saveVersion=1；本次字段为 lampOil、statNodes（core/base/wick）、bestKills、bestScore、totalRuns、wins、activeRunId、lastCompletedRunId。未实装功能的存档字段暂不创建。
- EmberSave 为游戏入口，EmberSaveStore 封装存档事务，EmberMetaRules 提供数值，EmberSaveData 为无 Unity 对象引用的数据。首次无档时迁移 PlayerPrefs 的 Emberlight.BestKills，保留原键但不再写入。
- 写入使用临时文件并保留前一次完整 .bak。读取主档失败则保留损坏文件的唯一副本并尝试备份；都不可用时建立新进度。遇到未来版本保存原文件且阻止覆盖。购买/开局/结算只有写入成功才更新内存，失败时可重试；同一 runId 不能重复领取。
- 新增 EmberMetaPanel 与 Emberlight/Validate meta progression 开发检查入口。检查使用独立临时目录，不触碰玩家实际存档。
- 本次不启用武器门槛，六把武器仍全部可用；不接入已退出卡池的旧起始词条。图鉴与成就也未实现，后续需按 Gods-Select-v3 再对齐。
