# 护盾与回血道具

2026-09-13，jack 确认护盾参考数值除以 2。

- 新通用词条 ID4「护盾」：青铜 250、白银 500、黄金 750、钻石 1250。按幸运决定品质，加入前三张基础词条候选，不占武器槽。
- 选择后立即增加当前护盾，重复选择可叠加。受伤先应用难度倍率，再扣护盾，溢出部分扣生命；沿用受击保护时间。护盾不自动恢复，新局清零，无局外存档。蓝色 HUD 条显示剩余护盾。
- 普通敌人最终死亡有 8% 概率掉回血道具，带词缀敌人 20%，Boss 100%，分裂子体不掉。重生读条前不算最终死亡，不重复掉落。
- 绿色白十字补给每个回复 20 HP，上限为最大生命。受伤时在 1.5 单位内吸附，0.5 单位内拾取；满血不消耗。掉落物保留 60 秒，暂停与选卡时计时冻结，普通换波保留，新局/退出清理，上限 24 个。
- 最终 Boss 仍正常胜利结算，结算后不继续拾取。护盾与回血是独立数值，回血道具不补护盾。
- 普通卡牌稀有度仅显示一次名称；新武器/专属/质变保留类型与单个稀有度。
- 新增开发检查 Emberlight/Validate survival；试玩手感仍由 jack 验收。
