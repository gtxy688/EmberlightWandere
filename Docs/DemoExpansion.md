# 2026-09-13 Demo 完善

## 七项更新
1. 自动选敌仅针对摄像机内目标，并避开顶部状态栏区域；所有玩家伤害均检查敌人是否在画面内。火球离开可战斗视口后销毁，防止屏外击杀。
2. 普通敌人显示随生命变化的头顶血条；Boss 使用固定顶部血条。
3. 战斗顶部删除游戏名，改为计时、击杀、生命条、经验条与暂停按钮。暂停、结算、升级时隐藏战斗状态栏。
4. 地图边界为 ±22，围墙位于 ±22.65，内侧配合玩家半径，灯柱与石块帮助识别边界。敌人移动也限制在场地内。
5. 词条颜色对应升级后等级：1 青铜、2 白银、3/4 黄金、5 钻石；不是额外随机稀有度，不改变原有数值与抽取概率。
6. 长夜守卫：第 480 秒出现，独立冠冕外观和顶部血条；追猎、冲刺预警、冲刺、恢复、地面爆发交替，半血时加快节奏并增加爆发区域。击败即获胜。仅在战斗状态推进招式，升级与暂停会冻结预警。
7. 启动时异步加载中文字体、预热共享精灵并准备界面；至少展示约 1.4 秒加载流程，完成后显示“烬灯行者 / EmberlightWandere / 提灯入夜，以火破晓。”以及按任意键或点击继续。继续输入仅在准备完成后启用。

## 模块
- EmberWorld：可见范围、地图边界、敌人血条。
- EmberHud：生命、经验与 Boss 状态。
- EmberBoss：明确状态机与伤害预警。
- EmberIntro：加载和标题输入。
- EmberExpansionChecks：三种宽高比的范围检查、边界、等级颜色规则和经验回归；编辑器 Boss 试玩菜单。
