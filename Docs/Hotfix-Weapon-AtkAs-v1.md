# Hotfix · 单武器攻/速 + 全体增幅 + 休闲血量（2026-09-14）

## jack 口径（定稿）
- **伤害增幅**：全体；名称/文案「全体伤害增幅」。
- **攻击力 / 攻速**：只加**对应已有武器**；不另开全局攻击力（防早期伤膨胀）。
- 数值档不变：攻 铜/银/金/钻 +10/20/30/40%；速 +10/20/30/50%。
- **休闲**怪物血量：`HealthMultiplier` **0.5**（相对标准一半；原 0.75）。

## 同屏唯一（jack 确认）
「每种最多一张」按**具体种类**计，不是笼统「攻击」：
- ✅ 可同屏：`火球·攻击力` + `环火·攻击力` + `全体伤害增幅`
- ✅ 可同屏：`火球·攻速` + `穿透·攻击力` + `幸运`
- ❌ 禁止：两张都是 `火球·攻击力`
- ❌ 禁止：三张都是 `全体伤害增幅`（或同一全局 Id 重复）

唯一键：`(Id, WeaponId)`；全局词条 `WeaponId = -1`。

## 数据
- `EmberOffer` 增加 `WeaponId`（全局=-1；攻/速必填已有武器 Id）。
- 全局 `DamageBonus` 停用；`DamageMul = (1+DamageAmp)`。
- 单武器攻击 → `weaponMagnitude[weaponId]`；单武器攻速 → `weaponAttackSpeed[weaponId]`。
- 出卡候选：幸运/全体增幅/护盾各 1；对**每把已有武器**各可出攻击力、攻速；再加专属/质变。
- UI：`{武器名}·攻击力` / `{武器名}·攻速`；增幅名「全体伤害增幅」。

## 武器接线
| 武器 | 伤害 | 攻速 |
|------|------|------|
| 火球 | `*(1+mag)*(1+amp)` | CD `0.8/(1+as)` |
| 穿透 | 同上 | CD `1.1/(1+as)` |
| 烬蝶 | 同上（已有 mag） | CD `2.0/(1+as)` |
| 火雨 | 同上（已有 mag） | CD `3.0/(1+as)` |
| 环火 | DPS×(1+mag)×(1+amp) | 转速 `spin*(1+as)` |
| 燃地 | DoT×(1+mag)×(1+amp) | tick/间隔 `/(1+as)` |

## 验收
1. 双武器时可同屏两张不同武器的攻击力 + 全体增幅。  
2. 同武器攻击力不会出现两张。  
3. 攻击力只抬对应武器；全体增幅抬所有。  
4. 休闲怪血为标准 50%。  
5. 数值档不变。
