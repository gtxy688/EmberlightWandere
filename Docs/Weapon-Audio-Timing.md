# 武器音画事件对齐

按 jack 反馈修正声音事件，不修改伤害数值：

- 火球、穿透、烬蝶在发射时播放短声音，从样本起点开始；各自相对增益 0.45 / 0.55 / 0.45。
- 火雨保持实际落地帧触发，增益 0.75。
- 火环不再在生成时响，仅在造成有效伤害后响，最多每 0.35 秒一次，增益 0.28。
- 燃地、火海及其他武器留下的燃烧地面不在铺设时响，只在实际伤害后响，最多每 0.7 秒一次，增益 0.35。
- 连续接触伤害不再叠加通用命中声音；由 DamageFrom 的同一伤害实现完成可见性和伤害检查，生命实际下降才触发专属声音。
- 优先采用项目已有 Generated 短素材。删除基于猜测秒数跳过长音效开头的武器调用，原长素材仍保留作缺失回退。
- 普通 PlayOneShot 音量由 AudioSource 使用一次设置值，消除先前重复乘音量的情况。

需要用户试玩确认声音力度和实际音画观感；编译与触发路径检查不等价于听感验收。
